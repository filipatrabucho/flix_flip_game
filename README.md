# Fix & Flip Tech — v0.7 (materiais 3D)

Projeto Godot 4.3+ com materiais procedurais PBR novos: albedo, normal e roughness para madeira, reboco, betão, alumínio, polímero e tapete de corte. Texturas geradas localmente para este projeto.

Correções adicionais: caminho dos nós das ferramentas seguradas pela mão, sombras, intensidade de luz, interação bloqueada enquanto seletor TAB está aberto, menor ocupação do HUD.

**Nota de qualidade:** Estes materiais melhoram as superfícies mas NÃO substituem modelos 3D detalhados. O visual cinematográfico de referência não está alcançado. Não foi possível testar com o binário Godot neste ambiente.

Abrir o project.godot no Godot 4 e executar com F5.
